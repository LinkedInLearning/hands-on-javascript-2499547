# Portfolio

A static, single-page portfolio with two case studies: The Bean Box and Frosti (both by Ravens Tech).

- **Your details:** edit the `PORTFOLIO` block at the top of `main.js` (name, role, email, LinkedIn). Empty values stay hidden.
- **Preview locally:** `python3 -m http.server` in this folder, then open http://localhost:8000.
- **Host on Cloudflare Pages:** Workers & Pages → Create → Pages → Connect to Git, choose this repo, set
  **Root directory** to `portfolio`, leave the build command empty and the output directory as `/`.
  Or use **Upload assets** and drag in this folder.
